## Ejercicio 1: Bucles While

El motor de JavaScript utiliza un mecanismo llamado ASI (Automatic Semicolon Insertion o Inserción Automática de Punto y Coma) para colocar de forma inteligente los puntos y comas donde cree que terminan las sentencias.

Utiliza un bucle `while` para imprimir los números del 1 al 10.

```javascript
let num = 1

while (num <= 10) {
  console.log(num)
  num++
}
```
